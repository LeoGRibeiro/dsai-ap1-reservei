Dashboard Admin - Financeiro

1. O quê e por quê
Criação da seção Financeiro no painel administrativo para centralizar a visualização dos valores relacionados às reservas.

O objetivo é permitir que o gestor acompanhe de forma rápida os valores recebidos, os valores previstos e os valores pendentes, além de visualizar a evolução financeira das reservas e os valores previstos por quadra.

2. Critérios de aceitação
Cards Financeiros: A tela deve exibir os indicadores de Total Recebido, Total Previsto e Valor Pendente, utilizando os dados reais das reservas.

Total Recebido: Deve considerar os valores de sinal das reservas confirmadas.

Total Previsto: Deve considerar o valor total das reservas que não foram canceladas.

Valor Pendente: Deve apresentar os valores ainda pendentes das reservas confirmadas.

Evolução Financeira: A tela deve apresentar a evolução dos valores previstos das reservas dos últimos 7 dias, organizados por data.

Valores por Quadra: A tela deve apresentar o total previsto agrupado por quadra, considerando somente reservas que não foram canceladas.

Dados Reais: Os valores apresentados devem ser obtidos através do serviço de reservas existente no sistema, sem utilização de valores fictícios ou fixos.

Valores Monetários: Os valores devem ser apresentados no formato de moeda brasileira (R$).

Estado Vazio: Caso não existam reservas, a seção de valores por quadra deve informar que ainda não existem reservas para apresentar.
